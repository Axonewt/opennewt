工作原理

三步入门，即刻体验

从下载到开始使用，整个过程不超过 5 分钟。

下载 & 安装
从 GitHub Releases 下载对应平台的安装包，双击安装，无需任何依赖。
配置 LLM
在设置中填入你的 API Key（OpenAI / DeepSeek / Anthropic 等），或连接本地 Ollama 模型。
开始对话
选择模型，输入任务。Agent 自动调用工具链，读取文件、搜索信息、执行操作，一气呵成。
